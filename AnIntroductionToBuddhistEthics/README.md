ပုံတစ်ပုံစီ၏ ဖိုင်အမည်၊ PDF/ပုံနှိပ်စာမျက်နှာ၊ အရွယ်အစား၊ byte အရေအတွက်၊ SHA-256၊ မူရင်းနှင့် မြန်မာပုံစာ၊ ပုံပံ့ပိုးသူအသိအမှတ်ပြုချက်တို့ကို `docs/translations/buddhist-ethics-20261011/image-extraction/metadata.json` တွင် မှတ်တမ်းတင်ထားသည်။ ပုံပံ့ပိုးသူအသိအမှတ်ပြုချက်များကို မူရင်း Plates စာရင်း (PDF စာမျက်နှာ ၁၀၊ ပုံနှိပ်စာမျက်နှာ xii) မှ ထိန်းသိမ်းထားသည်။
